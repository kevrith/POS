# Mobile POS App

React Native mobile POS application for cashiers and managers.

## Features

- Quick checkout with barcode scanning
- Offline-first with local SQLite
- Cash drawer management
- Customer lookup
- Receipt printing (Bluetooth)
- Sales reports
- Inventory lookup

## Tech Stack

- React Native (Expo)
- TypeScript
- Zustand (state)
- TanStack Query (API)
- SQLite (local DB)
- Expo Camera (barcode)

## Setup

```bash
npm install
npx expo start
```
