# Mobile Driver App

React Native delivery driver app for e-commerce orders.

## Features

- View assigned deliveries
- Navigation to customer
- Order details
- Delivery confirmation
- Photo proof of delivery
- Earnings tracking
- Real-time location tracking

## Tech Stack

- React Native (Expo)
- TypeScript
- Zustand (state)
- TanStack Query (API)
- Expo Location
- React Native Maps

## Setup

```bash
npm install
npx expo start
```
