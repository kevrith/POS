# Mobile Customer App

React Native customer-facing mobile app.

## Features

- Browse products
- View promotions
- Loyalty points balance
- Order history
- Gift card balance
- Store locator
- Push notifications
- M-Pesa payments

## Tech Stack

- React Native (Expo)
- TypeScript
- Zustand (state)
- TanStack Query (API)
- Expo Location
- Expo Notifications

## Setup

```bash
npm install
npx expo start
```
